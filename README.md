# Voice Assistant 🤖

Голосовий помічник — відтворення проєкту з хакатону (без emergency services).

## Можливості

- 🌍 **5 мов**: українська, російська, англійська, угорська, французька
- 🌤️ **Погода** з геолокації (безкоштовний API Open-Meteo, без ключів) + поради про одяг
- 🎤 **Голосове керування** (Web Speech API — вбудовано в браузер):
  - «погода» / «weather» / «météo»
  - «котра година» / «which time»
  - «нагадай мені о 15:30 купити хліб» / «remind me to call mom at 17:00»
  - вітання, прощання, подяка, допомога
- ⏰ **Нагадування** — зберігаються в localStorage, спрацьовують зі звуком
- 📋 **Журнал** дій

## Як запустити

```bash
python -m http.server 8081
```

Відкрити http://localhost:8081/index.html

> ⚠️ Голосове керування працює в Chrome / Edge. Погода потребує дозволу на геолокацію.
