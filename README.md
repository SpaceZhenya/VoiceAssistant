# Voice Assistant 🤖

Голосовий помічник — відтворення проєкту з хакатону (без emergency services).

## Можливості

- 🌍 **5 мов**: українська, російська, англійська, угорська, французька — **голос озвучки змінюється разом з мовою** (🔊/🔇 кнопка вкл/викл, **свій акцент для кожної мови**: uk-UA, ru-RU, en-GB/en-US, hu-HU, fr-FR — для англійської можна перемикати 🇬🇧 UK / 🇺🇸 US; команда «які голоси» показує діагностику)
- 🌤️ **Погода** з геолокації (Open-Meteo + BigDataCloud reverse geocoding, без ключів) — показує місто + **розумні поради по одягу** (8 температурних рівнів + дощ/сніг/гроза/туман/вітер)
- 📅 **Прогноз на 3 дні** + 👕 **поради по одягу на кожен день** + 🌅 схід/захід сонця
- 💱 **Курси валют** USD/EUR → UAH (open.er-api.com, без ключів)
- 🧮 **Калькулятор** — «скільки буде 2+2*3», «what is 10/4»
- 🪙 **Монетка** — «підкинь монетку»
- 😂 **Жарти** — локальні, 5 мовами
- 🕐 **Час** і 📅 **дата** голосом
- 🎤 **Голосове керування** (Web Speech API — вбудовано в браузер)
- ✍️ **Текстовий ввід** — команди можна друкувати, якщо немає мікрофона
- 🧠 **Розумний агент**: пам'ятає твоє ім'я («мене звати Женя»), вітається за часом доби, відповідає на «як справи», «хто ти»
- 💬 **Цитати** — «цитата» (локальні, 5 мовами)
- ⏱️ **Таймер** — «таймер на 5 хвилин», звук по завершенню
- 🎯 **Чипи-команди** — клікабельні підказки під інпутом
- ⏰ **Нагадування** — зберігаються в localStorage, спрацьовують зі звуком (Web Audio API)
- 📝 **Замітки** — зберігаються в localStorage
- 📋 **Журнал** дій

## Команди голосом / текстом

| Команда | Мови |
|---|---|
| «погода» | погода / weather / météo / időjárás |
| «прогноз» | прогноз / forecast / prévisions / előrejelzés |
| «курс» | курс / currency / taux / árfolyam |
| «котра година» | котра година / what time / quelle heure / mennyi az idő |
| «яка дата» | яка дата / what date / quelle date / milyen dátum |
| «нагадай мені о 15:30 купити хліб» | нагадай / remind me / rappelle-moi / emlékeztess |
| «2+2*3» | калькулятор на будь-якій мові |
| «монетка», «жарт», «замітки», «привіт», «дякую» | на всіх 5 мовах |
| «мене звати Женя» | запам'ятовує ім'я |
| «хто ти», «що ти вмієш», «як справи» | розумні відповіді |
| «цитата» | цитата дня |
| «таймер на 5 хвилин» | таймер зі звуком |

## Як запустити

```bash
python -m http.server 8081
```

Відкрити http://localhost:8081/index.html

> ⚠️ Голосове керування працює в Chrome / Edge. Погода і прогноз потребують дозволу на геолокацію.
